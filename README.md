# Tree-Sitter experiments

These are just little experiments I wrote to help me understand tree-sitter better, and to get help.

Have fun and let me know if they bring you joy! <tree-sitter-experiments@pobox.madduck.net> is my address.

Each experiment consists of a grammar, possibly a scanner, and test cases.

## How to run

```
git clone https://github.com/madduck/tree-sitter-experiments
tree-sitter generate
tree-sitter test
```
